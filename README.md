## 🎨 About
Premium event planning website with a luxurious purple and gold color scheme. Features include service showcase, portfolio gallery with filtering, testimonials, and responsive design.

## ✨ Features
- Responsive design (mobile, tablet, desktop)
- Interactive portfolio gallery with category filtering
- 8 service cards with custom icons
- Client testimonials section
- Smooth scroll navigation
- Purple & gold luxury color palette

## 🛠️ Technologies
- HTML5
- Tailwind CSS (CDN)
- JavaScript (ES6)
- Font Awesome icons (SVG)
